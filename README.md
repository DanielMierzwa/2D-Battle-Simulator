# 2D-Battle-Simulator
Projekt prostego symulatora bitewnego z prostą fizyką. Był on formą nauki biblioteki SFML w C++. 
Jeśli potrzebujesz nieskompilowanego kodu jest on na branchu ``` source-code ```
## Opis działania
Można wybrać 4 rodzaje jednostek i ustawić je na jednej z 2 połówek planszy. Bitwa się rozpoczyna po kliknięciu startu.

Gdyby ktoś się zastanawiał nad cyferkami na przyciskach jednostek to jest to próba wprowadzenia systemu balansowani 2 armii, żeby armie o tym samym koszcie punktowym miały takie same szanse na wygraną.

# 2D-Battle-Simulator

A simple 2D battle simulator project featuring basic physics. It was created as a way to learn the SFML library in C++.

If you need the uncompiled source code, it is available on the `source-code` branch.

## How It Works

You can choose from 4 different unit types and place them on one of the two sides of the battlefield. The battle begins after clicking the start button.

If anyone is wondering about the numbers displayed on the unit buttons, they represent an attempt to introduce a balancing system for the two armies, so that armies with the same point cost have similar chances of winning.
